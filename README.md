# Dekiller — página personal

Sitio estático HTML/CSS/JavaScript para publicar en GitHub Pages.

## Probar desde Termux
Desde esta carpeta ejecuta:
```sh
python -m http.server 8080 --bind 127.0.0.1
```
Abre `http://127.0.0.1:8080` en el navegador del mismo teléfono.

## Antes de publicar
- Cambia los enlaces de TikTok y GitHub por tus perfiles reales.
- Sustituye `TU-CORREO@example.com` por un correo que quieras hacer público, o elimina ese enlace.
- Revisa el texto y elimina cualquier sección que no quieras compartir.
- No guardes contraseñas, tokens, documentos privados ni claves API en esta carpeta.

## Publicación gratuita
Puedes subir estos archivos a un repositorio público nuevo y activar GitHub Pages desde Settings > Pages. El archivo `index.html` debe quedar en la raíz del repositorio.
